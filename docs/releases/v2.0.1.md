# PatchPilot v2.0.1

Security-hardening patch on top of the local-only 2.0 release.

## Fixed

- Replaced predictable session-ID suffixes with cryptographically secure UUIDs.
- Reworked DOCX text extraction to select Word text/tab/paragraph nodes instead of repeatedly stripping arbitrary XML tags.
- Decoded Word XML entities exactly once, with ampersands handled last to prevent double-unescaping.

## Verification

- `npm run prepublishOnly`
- `npm audit --audit-level=moderate`
- `npm audit signatures`
- GitHub CI on Node.js 22 and 24
- CodeQL and package-security workflows
