# PatchPilot v2.0.0

PatchPilot 2.0 is a local-only major release. It removes the cloud-provider integrations from the 1.x line and rebuilds the agent/runtime boundary around reliable local inference, explicit permissions, and a denser terminal workflow.

## Breaking changes

- Removed Gemini, Gemini-Wrapper, OpenRouter, NVIDIA, and Codex provider routes and their credentials, setup paths, pricing tables, and compatibility code.
- Provider selection now accepts only `ollama` and `local-openai`.
- Replaced the broad legacy tool surface with nine focused tools and provider-native schemas.
- Removed manual reasoning-effort and thinking-mode commands; thinking follows model/runtime capability.
- Removed the old advisor-style planner/reviewer calls in favor of real isolated child-agent loops.

## Added

- Added local OpenAI-compatible runtime support for LM Studio/Bionic, MLX, llama.cpp, and vLLM.
- Added cross-runtime discovery, model ranking, capability probing, context-window measurement, and safe model substitution checks.
- Added native streaming for visible answers, separated reasoning where available, live throughput, and tool-argument write progress.
- Added structured tool-call validation and a bounded repair ladder for smaller local models.
- Added real `explore` and `general` child agents with isolated context, narrow allowlists, persisted traces, bounded steps, and abort propagation.
- Added context storage, pinning, export, clearing, automatic/manual compaction, and a visible context-pressure meter.
- Added flow-shell scrollback, multiline editing, prompt history, Markdown and syntax highlighting, command/config palettes, reduced motion, and denser status/todo rendering.
- Added model unloading for Ollama and supported LM Studio/Bionic instances.

## Fixed and hardened

- Prevented repeated todo/tool batches and empty protocol loops from exhausting an agent run without progress.
- Made cancellation stop model and child-agent work cleanly before sibling writes continue.
- Made blocked response-body reads honor cancellation and an idle timeout, and capped `fetch_url` downloads before full-body decoding.
- Prevented double-unescaping of HTML entities in fetched pages.
- Kept subagent telemetry distinct while preserving detailed traces outside the primary context.
- Unified permission-mode resolution, runtime aliases, subagent persistence, runtime-scoped model descriptors, and provider-specific settings.
- Bounded retained transcript state in the default Flow interface while preserving terminal scrollback.
- Improved final-answer/path honesty, tool errors, truncated output handling, response-format fallback, and context pruning.
- Removed stale cloud-provider documentation, showcase images, and accidentally tracked calculator/build artifacts.
- Updated Vitest to a release that fixes the current development-only path-traversal advisory.
- Made the release preflight tolerate a user-level npm `allow-scripts` policy without weakening that install policy.
