# PatchPilot v1.2.1

Patch release on top of v1.2.0.

## Fixed

- Fixed the installed/linked `patchpilot` command failing with `permission denied`: `tsc` does not preserve the execute bit, so a `postbuild` step now chmods `dist/cli.js` to `0755` after every build.
- Fixed the agent being unable to show code snippets. When it searched the code and tried to display a match, the model's JSON command envelope broke on raw newlines and stray backslashes (Windows paths, regex), failing with `Unexpected token …`. JSON repair now runs for any syntax error — not only control-character errors — and escapes raw control characters as well as backslashes that are not valid JSON escapes, then retries.
